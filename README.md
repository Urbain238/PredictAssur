# 🔮 PredictAssure — Étude de Marché & Tarification Actuarielle (Zone CIMA)

PredictAssure est une application Streamlit multi-pages dédiée à l'analyse du marché de l'assurance et à la tarification dynamique au Cameroun.

## 🚀 Fonctionnalités
- **Accueil** : Métriques clés du marché et navigation centralisée.
- **Collecte & Registre** : Saisie terrain de profils répondants et export multi-formats (CSV, Excel, PDF).
- **Dashboard Expert** : Visualisation multidimensionnelle, cartographie de la confiance et filtres régionaux.
- **Modèle Machine Learning & Actuariat** : Détection des personas, Random Forest et tarification sur-mesure.

## 🛠️ Installation & Lancement
1. Installer les dépendances : `pip install -r requirements.txt`
2. Lancer l'application : `streamlit run Accueil.py`
